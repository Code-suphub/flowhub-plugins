# Docker 与社交聚合 React 迁移

## 边界

- 页面使用 React + TypeScript + Vite + Tailwind CSS，优先 `@flowhub/plugin-common/react`。
- Rust 业务 API、权限模型和数据位置保持不变；不重新安装用户插件，不对真实容器或社交账号执行测试写操作。
- Docker 管理入口与桌面详情共用管理能力。桌面卡片、组件编辑器独立验收，不把管理页迁移称作整个插件全部迁移。
- 社交聚合后端仍提供演示会话；发送接口目前返回未授权。界面迁移不代表真实平台已接入。

## 验收

- 类型检查、各插件测试与构建通过。
- 只读预览禁止业务写入，错误与危险操作警告可见。
- Docker 的容器／Compose／镜像操作仍使用原接口，删除和项目停止保留确认及预览。
- 社交授权与回复分别提交；发送失败保留草稿，快速切换会话不展示过期响应。
- 消息桥验证父窗口与请求 ID；桌面详情保持 widget token 协议；超时及卸载清理待处理请求。
- 独立包资源通过 `node scripts/check-built-ui.mjs plugins/<id>/build` 检查；禁止未解析公共资源标记、越界资源、远程或内联可执行脚本。
- 手动检查浅色／深色、窄屏、键盘、弹窗和错误状态。

## 工作分工

两名 Luna 子代理分别负责 `plugins/docker`、`plugins/social-hub`；主代理负责公共打包资源校验、交叉审查与回归整合。
