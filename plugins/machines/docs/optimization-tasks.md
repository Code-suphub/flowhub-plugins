- [x] 1. 命令目标绑定：捕获提交时连接配置；配置变化取消排队任务；运行期间限制连接编辑。

- [x] 5. 堡垒机并发与诊断：按机器锁定；识别登录、连接、就绪和退出；保留退出原因与最近输出。

## 验证与行为

目标版本由工作台、采集和安装预览传入；CLI 从当前清单获取。排队任务再次校验配置并使用捕获的连接，避免执行时重新指向另一地址。

命令记录独立保留 90 天、最多 5000 条完成任务和 32 MiB 记录正文；运行与排队任务保留。密码、令牌、API 密钥等带名称字段尽力遮盖，未标明的敏感内容无法自动识别。数据文件权限为 600，清理释放空间达到阈值时压缩数据库。

手动断开的暂停标记存放在插件数据目录中。后台监控和插件重启保留暂停状态，点击连接恢复。

遮盖输入框不会改变远端终端回显。已移除本机 relay 脚本主动打印验证码的语句；远端程序仍需自行关闭密码回显。

验收：101 项 Rust 测试、46 项页面测试、类型检查、布局检查、深浅主题指纹和独立构建通过；工作台已检查 1400/600/380 宽度以及切换机器时清空草稿、键盘展开和关闭选择器。已重新加载到 FlowHub。

## 会话命令模板接入

执行按钮左侧改为公共组合框，读取已保存的模板，也支持直接输入和编辑完整命令，包括多行脚本。选择模板不会自动执行；点击执行后，使用已确认目标身份的共享会话执行，并保存命令输出与退出结果，命令超时为 60 秒。只读机器继续仅支持五条内置查询。执行后刷新并跟随最近输出，手动向上滚动时暂停跟随。

验证：102 项后端测试、50 项页面测试通过，涵盖多行模板中追加 ls、自定义命令、退出码、执行记录和只读权限；公共组合框原有选择行为与预览指纹保持通过。

## 组件监控来源与 Netdata 连接

组件下拉保留独立的机器和 Agent ID，并标明 SSH、Node Exporter 或 Netdata 来源。采集失败不再写入机器名称，失败选项明确显示“采集失败”；状态快照提供 Agent 的具体错误，避免同名 SSH 卡片正常时被误认为机器无法连接。

Netdata 请求保留系统代理；默认连接、HTTP 状态、响应读取或解析失败时，再直连同一 Agent 地址。默认和直连请求分别限制为 12 秒，响应仍限制为 8 MiB，禁止自动重定向。回归覆盖代理 502、响应中途断开、超过 12 秒的完整响应，以及同名来源的独立状态。104 项后端测试、51 项页面测试、类型、布局、指纹与构建检查通过；最后的网络改动另跑 Netdata 相关回归。
