# 轻量监控与本地历史

机器页面的「监控设置」管理采集来源和历史保留时长。填写 Node Exporter 的完整 metrics 地址后，通过 HTTP 读取两次计数器计算 CPU 和网速；留空使用原有 SSH / 堡垒机会话采集。地址须从运行 FlowHub 的电脑可达，不自动安装服务。Exporter 出错会明确显示失败，不静默切换到 SSH。

开启「后台监控」后，只在 FlowHub 运行且电脑唤醒时采集。退出期间不补采，历史曲线显示空档。SSH 和堡垒机来源提供 CPU、内存、根磁盘、负载、运行时间及上传/下载速率；网络采样汇总排除 lo、veth、docker、br- 的接口，额外采样约一秒，按实际时间差计算 KB/s。计数器重置时留空。Exporter 来源也支持网速，并可指定网卡。升级前没有采集的网速无法补回。

采样保存在插件数据目录 commands.sqlite3 的 metric_samples 表中，并随插件备份恢复。保留时长默认 30 天，可设置 1–365 天；保存设置及后台每分钟执行过期清理，同时最多保留 20 万条采样。达到数量上限可能使实际保留时间短于配置。清理释放的 SQLite 页面供后续写入复用，不承诺文件立即缩小。命令执行历史不受监控时长影响。

历史查询按时间桶聚合，缺失桶为 null，不填零。Netdata 旧配置保留用于兼容，但本版本不再启动其后台轮询。无需 Prometheus 或 Netdata 常驻服务。
