# 外设中心 · Device Center

FlowHub macOS schema 2 原生设备插件。v0.3.3 使用 React 管理页：双栏设备卡片、按需详情弹窗、紧凑供电读数和连接事件，支持深浅主题与原有组件配置。修复 WKWebView 中详情弹窗的 Tab 循环与关闭后的卡片焦点，以及帮助气泡需要按两次 Esc 才收起的问题。

## 页面与只读预览

管理页入口 `ui/index.html`，组件详情入口 `ui/widget-detail.html`；两者使用同一 React 页面。桌面卡片和组件编辑器保持已有配置协议。

```sh
pnpm install --frozen-lockfile
pnpm dev
# http://127.0.0.1:5188/ui/index.html
```

独立浏览器仅显示明确标注的示例数据，不扫描或操作真实设备。支持 `?view=power` / `?view=bluetooth` / `?view=events`，以及 `?scenario=missing` / `stale` / `error` / `unplugged` / `empty` / `long`。嵌入宿主后只通过真实插件 RPC 读取数据，不允许查询参数切换成假数据。

```sh
pnpm test
pnpm build
node scripts/browser-acceptance.mjs /absolute/path/to/evidence
```

浏览器验收使用独立无头 Chrome，在不透明 sandbox iframe 中加载实际构建产物与宿主等价的 CSP，验证筛选、弹窗、焦点恢复、供电缺失/失败、深浅主题、窄屏与组件入口。设备数据使用夹具，系统图标通过构建包内 helper 获取。它不移动鼠标，不修改剪贴板、实际设备或安装版。

实机验收与分项提交记录见 [改造验收清单](docs/redesign-acceptance.md) 和 [正式安装版验收](docs/installed-acceptance-2026-11-07.md)。浏览器验证不代替 WKWebView、真实输入法、热插拔与安装版验收。

## 运行中插件 CLI

在 FlowHub 打开外设中心后，从实际安装目录运行以下命令。

```sh
./bin/flowhub-device-center --cli status
./bin/flowhub-device-center --cli refresh
./bin/flowhub-device-center --cli k75 status
```

`status` 读取运行中插件的缓存，`refresh` 立即重新扫描系统外设并更新同一份缓存。两者返回相同的服务 PID，界面下次读取时会拿到更新结果。CLI 使用插件数据目录下的私有 Unix socket，只接受固定命令。成功输出单行 JSON，失败返回 JSON 错误及非零退出码。隔离验收可通过 `FLOWHUB_PLUGIN_DATA` 指定现有的专用数据目录。

在另一台机器通过 SSH 运行目标机的同一条命令即可。Toolkit 可作为 SSH 客户端；需要将目标机上实际的插件二进制绝对路径作为一个参数传入。

`k75 status` 仅匹配 USB ID 为 `258a:0112` 的有线 K75 RGB，读取 USB 设备版本、厂商配置诊断字节和电源原始字节。设备版本 `0x4023` 可报告 Win／Mac 模式，其他版本显示未知。验证范围与剩余项见 [CLI 和 K75 验收清单](docs/cli-k75-acceptance.md)。

## 图标来源与更新

- 图中的手机屏幕只是设备家族的视觉示意，不读取设备壁纸，也不代表机身颜色。
- 苹果设备通过包内 Swift helper 调用公开 `UTType` / `NSWorkspace.icon(for:)` API，读取当前 macOS 已安装的家族图标。图像在后端进程内缓存，不随每次功率采样重新提取。
- 当前匹配 iPhone、AirPods、AirPods Pro、Magic Mouse、Apple 键盘和 MacBook 家族；未声明的系统类型自动回退，不用通用文档图标假装设备图片。该能力依赖已安装的系统资源，不保证覆盖刚发布的型号。
- 桌面组件、设备卡片和详情使用同一套设备图片。已收录的型号使用本地缓存的参考图，其余设备使用可用的 macOS 家族图标或包内 `ui/assets/` 彩色类别插图。导航和操作图标使用 `@mdi/js 7.4.47`，许可见 `ui/licenses/material-design-icons.txt`。
- 首批参考图收录 Pixel 8 Pro、Logitech MX Master 3S、LG UltraFine 5K。只有精确匹配时，后端才会在后台从固定的 Wikimedia Commons 路径下载缩略图。缓存按型号和图片版本保存，跨进程复用。下载失败时继续显示本机图标，15 分钟后可随采集重试。详情提供图片作者、来源与许可。
- WebView 从后端接收有限大小的 JPEG 和系统 PNG，保留现有 CSP。请求只访问目录内固定 URL。系统图标解析参考 [device-icons](https://github.com/bkahlert/device-icons)。
- 珂芝 K75 的详情提供背光亮度、灯效、颜色、速度及 Mac／Windows 键位快捷键，还有官方说明书入口。K75 V2 等近似型号不会套用这份说明。该入口仅用于查看设备资料。

## 设备数据与安全边界

- Rust 每 45 秒只读运行系统 `system_profiler -json`，解析蓝牙连接列表、USB 拓扑、显示器和电源状态。
- 当 macOS 把 USB 设备命名为 `composite_device` 等通用名称时，使用 USB HID 报告补充名称。只有厂商 ID、产品 ID 和 USB 位置同时匹配且名称唯一时才替换显示名，保留原设备 ID 和 USB 分类。
- 蓝牙设备缺少电量时，额外只读运行 `pmset -g accps`（3 秒超时、64 KiB 上限），按唯一且完全匹配的设备名补充 macOS 配件电量。它不添加设备，不覆盖系统报告已有电量；查询不可用或同名设备无法区分时仍显示未知，不需要管理员权限。
- 桌面组件始终列出全部当前设备，在固定高度的列表内滚动；旧的 3/5/8 条上限也不再截断。点击统计按钮切换蓝牙、USB、显示器、ADB 分类；ADB 保留未授权、离线条目并标明状态，点击设备主体可查看详情。每条设备右侧的把手可拖拽排序，聚焦后也能用上下方向键及 Home／End 调整，拖动到列表边缘会自动滚动。各分类和外设中心组件共用本机保存顺序，刷新／重新打开／重启后保留；新设备追加，暂时离开的设备重连后恢复位置。仅保存设备哈希 ID 及排序版本，不保存 ADB 序列号；保存失败保留待保存顺序，可重试或撤销。刷新保留分类及列表滚动位置，拖动期间不重建列表；扫描失败或过期仍明确标为上次采集结果。
- 完整列表与排序的验证结果、正式替换证据和后续实机任务见[组件排序验收记录](docs/widget-order-acceptance-2026-11-07.md)。
- 供电来源独立通过只读 `pmset -g batt` 读取，不依赖电池或瓦数遥测。无内置电池的桌面设备不显示充放电状态；系统未提供实时功率时仍显示已确认的供电来源，不用估算或适配器规格填充缺失瓦数。
- 系统设备清单不回传蓝牙地址或硬件序列号；ADB 清单单独返回连接序列号供本地识别、搜索和复制，不写入连接事件或持久化文件。连接事件只保存在进程内存。
- 详情显示该设备最近三条连接事件，可通过“相关事件”查看完整记录。首扫建立基线，之后记录检测到的蓝牙、USB、显示器连接变化，以及 ADB 各线路的连接、断开或授权等状态变化。采集失败保留上次状态，最多保留 60 条事件，插件后端重启后从新基线开始。
- 蓝牙和 ADB 详情中的“电量历史”展示采样时间、读数和来源。默认保留 48 小时，可改为 7 天，设置对全部设备的电量历史生效。使用现有采集，读数或来源变化时记录，稳定时每 15 分钟留一点。成功采集但未取得电量时留空，长时间缺少样本时曲线也会断开。日志只写本机，按保留时间及容量清理。
- ADB 后台以 10 秒间隔运行固定 `adb devices -l`，列表查询上限为 5 秒、128 KiB 和 256 条。使用本机已有 Platform-Tools，型号、序列号及连接方式按真实输出显示。本地转发和 IP:端口标为 TCP/IP。查询可能启动本机 ADB 服务。已授权在线连接通过固定的 `adb -s <已发现的连接标识> shell dumpsys battery` 读取电量。每批最多 4 路并行，单次最多 1.25 秒、8 KiB，批次预算 2.5 秒。页面仅能请求刷新，设备目标由本机 ADB 列表确定。[ADB 状态说明](https://developer.android.com/tools/adb#devicestatus) · [Android 诊断接口](https://developer.android.com/tools/dumpsys)
- ADB 主页面和桌面组件在名称旁显示连接状态。已连接为绿色，离线、未授权等为红色，过期数据标明“上次”。电量未知时不显示百分比。低于 30% 默认标红，设备页的“电量设置”可改为 0 至 100，0 关闭提醒。详情可保存或清空别名，支持按别名、型号、序列号及连接状态搜索。别名按连接哈希 ID 保存在本机，原始型号和序列号仍可查看。
- 外设中心只读使用 Toolkit 的 `~/.config/toolkit/adb-devices.json`。自定义路径可通过宿主进程的 `FLOWHUB_TOOLKIT_ADB_CONFIG` 指定绝对路径。FlowHub 的本地显示别名优先，清空后采用 Toolkit 别名。已确认同一登记硬件身份的连接共用一张卡片，原线路的排序位置可继承。已登记入口可在另一条线路确认设备身份后显示在同一张卡片里，在线但未读到身份的入口标为“身份待核对”。详情列出本机观察到的 USB 与网络线路及各自状态。通过 Tailscale 对端地址或 EasyTier 本机监听端口确认网络来源，其他 TCP 连接仍标为 TCP/IP。
- 在线 ADB 设备的详情提供整机 CPU 使用率、已用／总内存，以及内部存储已用／总量、使用比例和可用空间。打开详情或点击「重新采样」时，通过当前设备的 ADB 连接读取 Android 内核数据与 `/data` 分区；不重复计算共享存储，不包含 SD 卡。可用空间使用系统读数，可能扣除保留空间，因此与已用量相加不一定等于总量。各项独立显示，无法读取时标为「未提供」。即时采样在内存缓存 5 秒，历史按下述分钟频率记录，不记录各 App 用量。
- 「历史曲线」可切换 CPU、内存和存储，悬浮／聚焦后用左右键及 Home／End 查看某次采样的时间、比例及绝对用量。外设中心运行时默认每分钟记录在线且已授权的 ADB 手机，最多同时 16 台；数据仅保存在本机，保留 48 小时，可改为 7 天或暂停记录。首次只有一个点，下一次采样后形成曲线；离线、失败、暂停和重启会断开曲线。CPU 记录每分钟一次的短采样，不代表整分钟平均值。电量历史与性能历史分别设置保留时间。
- 已加载的外设中心可通过后端 `--cli status` 查看设备 ID，再用 `--cli adb performance <id> [--refresh]` 读取同一进程的即时采样、`--cli adb history <id>` 读取已保存曲线。即时采样首次返回 `pending` 时稍后不带 `--refresh` 再读；命令复用在线／授权检查和 5 秒缓存，不操作系统键鼠，不支持任意 ADB shell。性能历史只保存设备哈希 ID、时间与读数，私有文件限制为 16 台设备、每台最多 10082 个点，超出保留时长或容量时清理旧数据。
- 桌面组件拖拽时浮起一张设备卡片，邻行滑动让出落点。位置判定基于原行中线，松手后才保存，Esc 取消。系统减少动态效果设置会关闭邻行滑动过渡。
- 显示器卡片和桌面组件将已知像素尺寸显示为 720P、1080P、2K（2560 × 1440）、4K、5K、6K、8K，并保留刷新率；竖屏按相同像素对识别，非标准尺寸保留准确数值，不按界面逻辑尺寸猜测档位。完整像素尺寸仍可在详情或悬停提示查看。显示器卡片优先使用系统报告的像素分辨率及刷新率，界面逻辑尺寸单独放在详情中；缺少像素数据时只标为显示模式。内置／外接类型优先读系统报告，缺失时通过在线显示器 ID 查询 CoreGraphics，仍无法确认则显示类型未知。
- 显示器分组与显示器详情提供“显示设置”，打开 macOS“系统设置 → 显示器”；桌面组件的显示器详情同样支持。进入系统页后选择目标屏幕，调整分辨率、刷新率、镜像／扩展及屏幕排列。此入口不自动选中某台屏幕或改变配置，独立浏览器预览禁用该操作；失败时原页面显示错误。后端仅打开固定系统设置 URI，5 秒超时，不接受页面传入的 URL 或命令。
- 功率采样间隔在组件编辑器配置，支持 5/10/30/60 秒，默认 5 秒；控制可见页面的刷新与后端缓存，编辑器不轮询，多个页面共享较新的采样。主插件页面默认 5 秒，设备目录扫描仍为 45 秒。小窗不显示采样间隔。
- 电池接口采样只读调用 `ioreg -a -r -c AppleSmartBattery`（3 秒超时、2 MiB 上限）。输入功率读取 `PowerTelemetryData.SystemPowerIn`（mW），整机功耗读取 `SystemLoad`（mW）；缺失时仅接受 `BatteryData.AdapterPower/SystemPower` 的真实浮点 W 值，不猜测旧整数编码的单位。
- 电池接口缺少整机功耗或外接输入读数时，只读连接 `AppleSMC`，读取 `PSTR`（整机功耗）和 `PDTR`（直流输入），仅补充缺失值；不覆盖已有电池遥测，不在电池供电时填入外接输入，不用 CPU/GPU 功率相加冒充整机功耗。无需管理员权限或特权服务。缺少传感器、权限受限或数值无效时保留未知，并释放每次采样的连接。已在 M4 Mac mini / macOS 15.5 实机验证；其他机型按传感器可用性回退。
- 电池侧功率由电池电压（mV）×有符号电流（mA）/1,000,000 估算，正值为充电、负值为放电、0 为电池待机。拔掉电源后不沿用缓存中的外接输入值。系统传感器本身可能延迟，不能视为外置功率计测量。
- 适配器规格、输入功率、整机功耗与电池功率分别显示；不同字段可能不是同一时刻采样。未知数值显示未提供，查询失败会清除功率值并显示错误。无电池或缺少遥测的机型不保证可读。
- iPhone 信任状态、USB PD 线缆能力以及各外设独立耗电功率尚未实现；整机功耗不代表独立供电的外接显示器耗电量。

## 构建与安装

macOS + Xcode Command Line Tools（Swift）+ Node.js 22+ + pnpm 10.15.1 + Rust stable：

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
```

FlowHub 的「插件市场 → 安装开发目录」选择 `plugins/device-center/build/`，不要选择源码目录。运行前先检查本地安装来源是否更新到了目标版本，并完成真实 FlowHub 页面视觉与数据验收。
