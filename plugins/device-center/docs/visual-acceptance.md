# 外设中心 V0.2.0 视觉验收规范

原型为用户最初确认的「FlowHub · 外设中心」暖白色 macOS 桌面效果图。**不得把 AI 原型图本身当作最终运行截图**，也不得为了匹配示例而伪造真实设备数值。

## 按原型保持的固定结构

- 浮动窗主体中的左侧导航（约 207 px），包括 FlowHub 品牌、概览、蓝牙、USB、显示器、供电、历史事件和设置。
- 顶部标题、描述、搜索及图标操作区域；圆形标题图标，轻浅色背景。
- 统计为**一行五张**概览卡：全部、蓝牙、USB、显示器、异常。
- 主体为蓝牙 / USB 双列，下面显示器 / 供电双列，最后最近事件的整行时间线。
- 实物视觉只在已知准确模型的原型示例中使用，未知设备显示同风格 SVG，不能按模糊名称编造准确图片。
- 桌面卡片采用单独插件 widget 入口，不当作主页面上的第二张漂浮窗口。

## 可运行页面的验收

- 原型桌面宽度：1168 px（内容区内部），同时验证宿主 800 px 和 520 px 窗口宽度。
- 使用 Playwright 自动截图，检查布局无溢出、脚本/资源无报错、所有交互可点击。
- 运行截图应与原型做并排比对，重点检查：统计卡信息层次、两列比例、设备图片、信息密度、边框/圆角/阴影、响应式切换点。
- 低于 800 px 允许按实际可读性重排；此时不是强行把五列压成不可读的一行。
- 对照时排除随系统变化的型号、电量、数量、日期和供电功率。

## 安全与限制

- 图片素材来自用户认可的 AI 原型局部裁剪，仅作为原型视觉占位，不能声称真实型号照片或厂商素材授权。
- 当前 macOS 主程序原生协议资源 MIME 白名单包含 PNG/SVG，不支持 WebP；因此此版使用 PNG，不修改主程序 CSP。
- 自动浏览器截图**不等于**安装版通过。真实安装仍需宿主插件菜单/iframe、原生 RPC、CSP 与 macOS 设备识别验收。
