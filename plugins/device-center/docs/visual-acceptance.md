# 外设中心视觉验收

v0.3.0 已用紧凑卡片与弹窗替换旧版大仪表盘；原 1536×1024 原型不再作为验收基线。

当前基线：800×560 中显示九台示例设备；双栏横向小卡片、按需详情弹窗；供电读数标签和值垂直相邻，规格为三个短信息组；冷灰白/石墨/蓝色，支持宿主深浅主题。窄窗口改为单栏。

自动验收入口：先 `pnpm build`，再 `pnpm test:browser`。截图与 report.json 默认输出到忽略的 screenshots 目录，支持参数指定 Git 外目录。

系统图标从当前 macOS 读取，类别图标随包发布。没有匹配资源时使用类别图标，不复用演示产品照片，不伪装实时壁纸或真实配色。

完整检查、已验结果和原生待验项见 [redesign-acceptance.md](redesign-acceptance.md)。
