## Mac mini 正式安装版

- [x] 通过屏幕共享操作插件市场，备份 0.3.15 包和注册信息后更新到 0.3.16。核对 29 项文件的 SHA-256、已注册目录及 FlowHub 正式宿主的子进程。其他插件注册项和目标插件权限与更新前一致。取证见 `installed-proof.json` 和 `install-staged.json`。
- [x] 从安装版「外设中心 → Gaming Keyboard」打开详情，显示「Mac 模式」及 USB 设备版本 `0x4023`；同一运行中后端的 CLI 返回 `osMode: mac`。
- [x] 在现有小窗顶部右键选择「编辑组件」，正式编辑器显示「展示内容」、三个勾选项和排序把手。保留了原配置；更新前已经打开的小窗仍显示旧的卡片排布。
- [ ] 使用 `Fn + A` 和 `Fn + S` 各切一次，观察 0.3.16 详情与小窗跟随更新，结束后恢复原模式。旧版已有实体切换的读回记录。
- [ ] 在桌面组件编辑器启用「K75 键位模式」，拖到首位并关闭「设备列表」，保存并重新打开。核对仅显示所选卡片且顺序正确；重新启用列表后检查设备分类、滚动和设备行排序。
- [ ] 拔插 K75 或切换到蓝牙，核对组件转为未检测到有线设备，重新接线后恢复读取。

只读 IORegistry 核对中，K75 的 USB 路线 `258a:0112` 有带 520 字节 Feature Report 的厂商集合。蓝牙 HID 路线 `3554:fa07` 的主集合为普通键盘，最大 Feature Report 为 1 字节，未发现该厂商集合。现有查询依赖有线厂商集合。USB 电源响应仍为原始字段，电量映射待验。
