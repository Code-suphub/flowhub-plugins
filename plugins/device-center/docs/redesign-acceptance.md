# 外设中心改造与验收

日期：2026-11-07。独立 worktree：`codex/device-center-redesign`，基于 `f3bc62c`；不修改 main 工作区。

## 已确认设计

双栏紧凑设备卡片、点击详情弹窗；冷灰白/石墨/蓝色。供电使用标签、数值、来源垂直相邻的三个功率卡片，规格与供电来源以短信息组呈现。常驻右侧详情不属于本次推荐方案。

## 分项进度

1. 系统图标服务与素材来源：独立 Swift helper 使用公开 NSWorkspace / UTType API；Rust 仅调用包内固定 helper、三秒超时、输出限额与 PNG 白名单，进程内缓存。类别兜底使用 Material Design Icons 的选定图标，不执行在线图库查询。
2. 管理页迁移为 React + TypeScript + Vite + Tailwind，复用公共交互组件；接回原生设备、供电和事件数据。
3. 组件卡片与配置兼容、深浅主题、键盘、窄屏、数据缺失/过期/错误、离线打包回归。

每项验证后独立提交；下列实机验收不能由编译或浏览器预览替代。

## 图标方案

- [device-icons](https://github.com/bkahlert/device-icons)：研究 Finder 设备图标解析方式。该项目代码 MIT，导出的系统图像由 Apple 提供。本插件不复制其导出图集，运行时通过公开系统 API 读取本机资源。
- [Material Design Icons](https://github.com/Templarian/MaterialDesign)：用于手机、键盘、显示器等类别兜底；并非所有新型号的商品照片数据库。
- 系统图标是设备家族示意，不保证匹配真实机身颜色、型号细节或手机当前壁纸。只依靠实际可用字段匹配，不按名称猜测硬件颜色。
- 系统图标跟随已安装的 macOS 资源，不保证覆盖刚发布的型号；没有合适资源时稳定回退到类别图标。无外部图片请求，也无需定期联网抓取素材。
- 设计稿中彩色手机屏幕为生成图片的示意，不是动态壁纸读取功能。
