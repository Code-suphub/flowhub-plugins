## 图标方案

- [device-icons](https://github.com/bkahlert/device-icons)：研究 Finder 设备图标解析方式。该项目代码 MIT，导出的系统图像由 Apple 提供。本插件不复制其导出图集，运行时通过公开系统 API 读取本机资源。
- [Material Design Icons](https://github.com/Templarian/MaterialDesign)：用于手机、键盘、显示器等类别兜底；并非所有新型号的商品照片数据库。
- 系统图标是设备家族示意，不保证匹配真实机身颜色、型号细节或手机当前壁纸。只依靠实际可用字段匹配，不按名称猜测硬件颜色。
- 系统图标跟随已安装的 macOS 资源，不保证覆盖刚发布的型号；没有合适资源时稳定回退到类别图标。无外部图片请求，也无需定期联网抓取素材。
- 设计稿中彩色手机屏幕为生成图片的示意，不是动态壁纸读取功能。
