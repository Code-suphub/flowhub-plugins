## 范围

- 设备页显示器分组及显示器详情新增“显示设置”，打开 macOS“系统设置 → 显示器”。桌面组件详情走相同后端入口。

## 正常安装版

- [ ] 市场更新至 0.3.4，核对注册目录、版本、包指纹和新插件进程。
- [ ] 设备页点击“显示设置”，系统实际进入“显示器”页。
- [ ] 点击某台显示器卡片仍打开详情；详情按钮可用 Enter／Space 触发系统页。
- [ ] 桌面组件进入显示器详情，再打开系统页。
- [ ] 返回 FlowHub，详情仍保留；Esc 关闭并回到原卡片，普通外设详情没有此按钮。
