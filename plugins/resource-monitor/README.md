# 应用资源监控

FlowHub schema 2 独立原生插件，支持 macOS Apple Silicon / Intel。显示应用占用排行、固定顺序的进程详情弹窗，以及 Arc 标签进程、Codex 对话工作进程的关联，并在确认后手动结束进程。插件使用当前用户权限，不申请 root。Arc 标题读取和跳转需要系统自动化授权；可选的任务管理器读取需要用户在系统设置中允许 FlowHub 辅助功能权限，插件不会自动授予权限。

## 构建与安装

```sh
pnpm install --frozen-lockfile
pnpm run build
```

在 FlowHub「插件市场 → 安装开发目录」选择本插件的 **`build/`**。启用后侧栏出现「应用资源监控」，宿主通过 `statusSurface` 自动接入菜单栏状态；主页面「桌面与菜单栏」打开组件画布。也可在画布添加「应用资源监控」卡片。卡片支持按内存/CPU 排序、显示 3–10 项或关注单个应用，点击应用进入对应进程详情。卡片内不直接执行清理。

源码位于独立的 flowhub-plugins 仓库，宿主无需重新编译。使用 React + TypeScript + Ant Design + Tailwind v4；复用 `@flowhub/plugin-common/react` 的基础控件和 `common-components` 的 antd 主题配置。`StyleProvider layer` 与 `theme, base, antd, components, utilities` 保持样式顺序。构建产物为自包含包，不依赖源码路径、CDN 或内联脚本。

## 数据与来源

- Rust 通过 macOS libproc 每 5 秒采样一次，界面不可见时停止页面轮询；后台采样供菜单栏和卡片共用。宿主每 15 秒读取状态缓存，卡片每 5 秒读取缓存，不触发额外采集。插件停用/宿主退出后采集进程结束。
- **内存足迹（默认排序）**通过 `proc_pid_rusage` 的 `ri_phys_footprint` 读取，包含脏页、压缩与换出等系统记账，更接近活动监视器的应用负担；同时单列保留 **RSS（当前常驻内存）**。二者口径不同，不能相加，不是“RSS + 全系统交换空间”，也不表示结束后必然释放的大小。应用合计按 PID 去重，缺项明确标注，不可读取时显示 `—`。菜单栏与卡片使用内存足迹，卡片另显示 RSS。
- CPU 使用两次采样间的累计 CPU 时间差，单核 100%，多核可超过 100%。首次或没有足够间隔时显示采样中。系统同时显示物理内存、交换使用量和系统报告的内存压力；无权限/不支持时显示未知。
- 应用包路径优先归组，嵌套 Helper 包归入外层应用。应用外子进程通过同 UID 的父进程链推断归属，明确显示「父进程推断」。没有应用祖先的进程按可执行文件、工作目录和 UID 归组；无法识别的进程保留原名。
- Android SDK 的 QEMU 模拟器独立归组，可显示虚拟设备名；其他 QEMU 仅标为虚拟机，不猜测管理工具。来源详情显示路径、工作目录、当前父进程、启动时间和用户 UID。父进程是当前关系，进程重新托管或父进程退出会影响归属，不能据此确定启动对话、是否闲置或是否可以安全停止。
- Codex 显示带对话标记的工作子进程合计，Arc 显示任务管理器报告的标签进程；不提供逐对话完整内存或 QQ 单个聊天的精确内存，不分摊共享界面、GPU 和服务。共享 PID 明确标记，各标签显示的相同进程占用不能相加。
- 原始 argv 仅在采样期间瞬时解析白名单 `-avd` 和 `--type`，不返回/保存完整命令行。用户读取 Codex 关联时，另对同 UID、Codex 进程树中的非受保护工作进程瞬时解析唯一的 UUID 环境字段 `CODEX_THREAD_ID`，核对读取前后的完整进程身份并清空临时缓冲；其他环境字段不导出。状态缓存只含不透明应用 ID、名称、计数和指标，不含 PID、路径、工作目录或标题。所有数据只在插件内存中，不记录活动历史。

## 手动清理

应用行和进程行统一提供「结束」。确认弹窗默认发送 SIGTERM，可显式打开「强制结束」切换为 SIGKILL；升级保留同一待确认目标集合与 30 秒有效期，执行时仍重新核对身份。不调用应用菜单中的“退出”，不承诺保存文稿，不自动升级，也不删除文件。结束渲染进程可能影响多个标签、对话或整个应用。

点击应用名打开固定尺寸的详情弹窗。刷新仅替换同一身份进程的数值，保持行顺序与分页；新进程追加，消失的进程留在原位置并标为已退出。PID 被复用时保留旧行、新增新身份，不替换用户正在查看的行。点击进程名可打开来源弹窗。

## 页面名称与跳转

详情中的「打开应用」激活所属应用。「页面与对话」仅在用户点击读取时取得标题和关联，标题不进入菜单栏缓存或磁盘历史。关联占用随常规进程采样刷新，映射五分钟失效；新任务、新标签、页面导航后需重新读取关联。未关联显示 `—`，不表示零占用或对话未运行。列表按关联状态初次排序，数值刷新不重排；支持标题、目录、PID 搜索和只看已关联。

- **Arc 标签与跳转**：通过本机 AppleScript 接口批量读取最多 500 个普通窗口标签，跳过隐私窗口；“打开”选择原标签并激活 Arc，不重新打开 URL。使用 AppleScriptObjC JSON 编码保留标题中的引号、换行与 Unicode；避开 JXA 的 `-1700` 属性转换错误。失败按权限、超时、类型转换和目标变化区分，不回显原始脚本与标题。
- **Arc 任务进程**：“读取 Arc 任务管理器”使用原生 Accessibility API 读取 Arc 自己的任务表；若未打开则尝试调用 Arc 自带的 Open Task Manager 菜单命令，也可手动从 Help → Troubleshooting 打开。未授权、窗口关闭、表格未就绪、未显示 PID 列分别提示。只读取当前可访问行，受任务管理器筛选、滚动位置和布局影响，界面显示当前读取范围；不自动滚动用户窗口。仅将显式标签任务、普通窗口已知标题及经核对的 PID/启动时间关联；不把子框架、扩展或未知/隐私标题绑定到普通标签。同名标签保留任务 PID 占用、禁用歧义跳转。缓存进程身份与当前采样身份不一致时拒绝关联；同 PID 多标签标记共享。不安装浏览器扩展，不启用 JavaScript from Apple Events 或远程调试端口。
- **Codex 对话工作进程**：只读 `$CODEX_HOME`（或 `~/.codex`）最高版本的 `state_*.sqlite` 中最近 100 个未归档、有用户消息的对话，只查询 ID、标题和项目目录；再按当前工作进程的 `CODEX_THREAD_ID` UUID 关联，可补充最多 100 个不在近期索引中的已识别对话。进程树只用于限制读取范围，不能代替 ID 证据。不安装 Hook、不连接或重启 Codex app-server，不读取消息正文，不将共享主进程、渲染器、GPU 或 app-server 分配给对话。未继承标记、身份变化、重托管或权限不足的进程保留未关联状态。通过已安装 Codex 的 `codex://threads/<UUID>` 跳转；索引/环境标记/链接属于本机版本适配，变更时会降级或明确报错。
- “进程”打开关联进程弹窗，可查看来源或逐个结束；进程详情页也显示已读取的页面名称，并可只看未关联进程。每个关联只引用完整身份，不复制或累加旧指标；PID 被复用不会将新进程计入旧关联。跨应用单列的 Codex 工作子进程也可出现在对话详情，不能再与应用排行相加。
- 跳转使用后端生成、绑定应用且 5 分钟有效的随机令牌，重新读取应用分组并核对令牌；前端不能提交任意 URL、脚本或应用路径。Arc 调用限时 15 秒，对话数据库只读并设置短锁等待，失败可重试。

清理分为 `terminate_preview` / `terminate_confirm`：预览重新采样，生成 30 秒有效、只能使用一次的随机令牌；确认重新核对 PID、微秒启动时间、UID、可执行路径和完整应用目标集合。集合变化、身份变化、过期或没有显式确认时拒绝。发送每个信号前再次校验身份，尽量缩小系统检查与发送信号之间的竞态窗口；macOS 此处使用 PID 信号接口，不能保证检查与信号原子化。

禁止结束系统核心路径、其他 UID、路径不可核实的进程、插件自身、FlowHub 及插件当前祖先进程。组内含受保护进程时禁止整组结束，仍可逐个操作允许的成员。单次最多 256 个进程。执行后分别显示信号是否发送、进程是否观察到退出和失败原因，SIGTERM 后仍存活的进程显示等待退出。采集失败保留旧数据与错误，超过 20 秒显示过期；清理始终先重新读取真实进程。

## 验证与预览

```sh
pnpm test
pnpm run build
node tests/smoke.mjs
FLOWHUB_ARC_SMOKE=1 node tests/smoke.mjs
FLOWHUB_ARC_TASKS_SMOKE=1 node tests/smoke.mjs
pnpm run dev
```

浏览器预览 `http://127.0.0.1:5186/ui/index.html`，卡片、编辑器、详情入口分别为 `widget-card.html`、`widget-editor.html`、`widget-detail.html`。浏览器只使用明确标注的模拟数据，清理和宿主设置禁用。自动化原生冒烟仅结束脚本自己创建的 `/bin/sleep` 子进程，覆盖普通/强制结束、未确认拒绝、身份变化拒绝和令牌复用拒绝。

原生冒烟创建专用带 UUID 标记的 sleep 子进程，检查 Codex 对话关联及其他环境字段不外泄。可选的 `FLOWHUB_ARC_SMOKE=1` 要求 Arc 已打开普通窗口，通过真实 RPC 检查标题上限与格式。`FLOWHUB_ARC_TASKS_SMOKE=1` 还要求调用环境已获辅助功能权限、Arc 任务管理器已打开且显示进程 ID 列，检查真实标签任务与完整进程身份关联。测试不切换标签、不打开新页面、不改变权限、不输出标题内容。

macOS 进程权限、全屏/多屏以及 Intel 原生运行仍需相应实机验收。本版没有自动清理、阈值结束、磁盘删除或缓存文件清理。
