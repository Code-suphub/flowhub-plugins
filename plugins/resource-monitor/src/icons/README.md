# Runtime icons

These unmodified logos identify the corresponding command-line runtime or service.
Native macOS application icons take priority when an application has been matched.
All assets are bundled locally; the monitor does not fetch icons at runtime.

- `python.svg`: Python Software Foundation, [official logo page](https://www.python.org/community/logos/), [source SVG](https://s3.dualstack.us-east-2.amazonaws.com/pythondotorg-assets/media/files/python-logo-only.svg), [trademark usage policy](https://www.python.org/psf/trademarks/).
- `postgresql.svg`: PostgreSQL, [official logo page](https://wiki.postgresql.org/wiki/Logo), [source SVG](https://wiki.postgresql.org/images/a/a4/PostgreSQL_logo.3colors.svg), [trademark policy](https://www.postgresql.org/about/policies/trademarks/).
