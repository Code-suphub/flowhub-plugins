# Docker 导航与日志交互验收

目标：`docker 0.2.0`。参考版本为 [Dockge 1.5.0](https://github.com/louislam/dockge/tree/1.5.0)，模块为 `frontend/src/pages/Compose.vue` 和 `frontend/src/components/Container.vue`。上游为 MIT；本轮只参考项目／成员／输出的组织方式，不移植上游源码、资源或服务端。

## 当前已有 → 本批变化

- 已有 Compose 分组、容器／镜像详情、日志过滤与三秒轮询。本批补返回路径、所属项目入口；进入资源不清空搜索，返回恢复原范围／标签／筛选、列表和详情滚动及来源焦点。窄屏同时恢复页面位置并确保来源按钮可见。
- 已有日志读取。本批把加载／失败状态移出日志正文，保留上次内容、提供就近重试和更新时间；向上阅读暂停跟随，可显式回到最新。
- 最近 8 个容器的日志视图仅缓存在页面内存；环境变化清空日志、选择、历史与待确认操作，迟到响应不串到其他对象。日志仍为最近 300 行的轮询，没有新增流式采集或自动终端连接。
- 原 Rust 引擎操作、context／对象校验、删除确认、加密及权限边界未重写；连接失败时保留列表并禁用旧对象修改和新终端连接。浏览、返回和选择标签本身不执行启停／删除／终端连接。
