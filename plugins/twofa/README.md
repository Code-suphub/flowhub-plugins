# 2FA 验证码

0.5.0 支持在导入窗口按 ⌘V 粘贴二维码图片，也可点击「扫描屏幕二维码」后拖动框选可见二维码，Esc 取消。屏幕框选目前仅支持 macOS，需要 FlowHub 的屏幕录制权限；没有权限时仍可截图后粘贴。框选最多等待 75 秒，选区 PNG 最大 2 MiB，临时文件在读取／取消／失败后清理。图片粘贴与屏幕选区均复用原有图片解码和账户预览，只有确认导入后才保存，不自动读取剪贴板或扫描屏幕。base64 0.22.1 的 MIT 许可随包保留。

0.4.0 新增本机二维码图片导入。导入窗口可选择 PNG／JPEG（最大 8 MiB）；图片在页面内通过 [jsQR 1.4.0](https://github.com/cozmo/jsQR) 解码，识别出的 TOTP 链接仍交给原后端校验，再核对账户并确认保存。图片不上传、不保留，不调用摄像头；请先裁剪为单个清晰二维码。jsQR 的 Apache-2.0 许可随独立包保留。

0.3.0 将账户列表重排为响应式卡片，参考 Proton Authenticator 的信息组织：发行方、账户名、服务缩写、验证码和到期进度集中显示，点击验证码复制，更多菜单保留编辑与删除。使用 FlowHub 主题和公共 React 组件自行实现，没有复制上游源码或图片。宽屏自动排列，窄屏单列；搜索、分步导入、旧账户加密存储及生成逻辑保持兼容。验收记录见 [清单](docs/acceptance.md)。

独立的 FlowHub TOTP 插件。支持 `2fa 名称` 搜索；管理页面按账户展示 6 位验证码与剩余秒数，输入名称或发行方即时过滤。

密钥使用插件数据目录中的本地随机密钥通过 AES-256-GCM 加密保存，文件权限限制为用户可读写；列表、日志和错误消息不会输出密钥。验证码由 [totp-rs 6.0.0](https://docs.rs/totp-rs/6.0.0/totp_rs/) 生成，支持 SHA1／SHA256／SHA512、6–8 位和 15–120 秒周期，不自动把验证码注入 SSH 或其他终端。

## 导入与兼容

「导入账户」接受手动粘贴的 `otpauth://totp/` 链接、选择／粘贴的二维码图片或屏幕框选。先在本机解析并展示账户、发行方、算法、位数和周期；解析不写账户文件，确认后才加密保存。账户名称可修改，同名账户需改名或取消，不覆盖原账户。HOTP、未知参数、重复参数、发行方冲突和不支持的生成参数会明确拒绝；错误不回显含密钥的完整链接。摄像头扫码、迁移二维码和密钥导出尚未实现。

原有加密文件、AAD 和本地加密密钥继续使用，读取不重写文件；缺少生成参数的旧账户仍按 SHA1／6 位／30 秒处理，原有 Base32 分隔符和已接受的 80-bit 密钥保持生成兼容。编辑导入的账户时，密钥留空保留原密钥，并保留其算法、位数和周期。新参数账户需要本版本生成器支持。

列表和导入预览只返回账户元数据；完整链接仅在当前表单内存和本机请求中使用，不写浏览器存储。验证码按各自周期缓存，到期才重新请求，八位验证码按四位分组展示，复制仍取连续数字。

在插件目录运行 `pnpm run build`，然后在 FlowHub「插件市场 → 安装开发目录」选择 `build/`。

## 前端

React + TypeScript + Vite + Tailwind CSS，复用 `@flowhub/plugin-common/react` 的输入、按钮、菜单、帮助气泡和对话框。新增／编辑与删除确认均为公共弹窗；旧 DOM 脚本和专用样式已移除。

- `pnpm install --frozen-lockfile`：安装锁定依赖。
- `pnpm run dev`：在 http://127.0.0.1:5197 打开只读模拟预览，不接触真实密钥。
- `pnpm test`：Rust、类型及客户端行为测试。
- `pnpm run build`：生成独立包并验证资源。React 编译为包内 IIFE，兼容插件自定义协议及既有 CSP，不依赖 CDN、外部源文件或新权限。

验证码仅暂存在内存；倒计时不重复请求有效验证码，到期后刷新。复制由用户点击触发，环境不允许剪贴板访问时可手动选中复制，不绕过沙箱权限。

独立预览仅允许解析内置公开示例链接，确认导入禁用，不处理真实账户。当前验证范围和宿主待验项见[验收清单](docs/acceptance.md)。
